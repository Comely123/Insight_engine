# 云端部署决策备忘

## 结论（当前）

1. **代码先上 GitHub**；云资源需用户明确配合后再部署。  
2. **面向国内用户优先阿里云**（备案、延迟、支付与合规路径更顺），不优先 Cloudflare Pages/Workers 作为主站。  
3. 域名：若已有可备案国内域名即可挂站；若无，可先用临时域名/IP 内测，再补 ICP。  
4. 数据策略：**分析完成后立即清除原文**；库中主要保留结构化结果与匿名检索归档。

远程仓库：[Comely123/Insight_engine](https://github.com/Comely123/Insight_engine) 仅版本管理，**不**托管用户私有库、上传原文或 API Key。

## 建议架构（待实施，非当前交付）

| 项 | 建议 |
|---|---|
| 云厂商 | 阿里云 ECS（小规格起步）或轻量应用服务器 |
| 应用 | Streamlit 公开站 `public_app.py`；管理端内网/SSH 访问 |
| 数据库 | 单实例 SQLite + 定期备份；多写并发再评估 PostgreSQL |
| 模型 | 默认同机或内网自部署 OpenAI 兼容接口；用户可自带 API Key |
| 网络 | HTTPS；不开放 DB 端口；管理端勿对公网裸奔 |
| 备案 | 有可备案域名再办 ICP；期间可用受限访问 |

## 何时部署

与用户另开协作：域名/服务器账号就绪 → 配环境变量 → 跑公开站 → 备份策略演练。

## 禁止事项

- 未经用户明确授权创建云资源或产生持续费用  
- 默认上传原始媒体、个人信息或 API Key  
- 实现登录绕过 / 验证码绕过 / 非授权爬取
